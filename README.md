# SportSwift Scheduling Hub — Flask + SQLite
BCA Mini Project — Beulah & Abirami

## Run in VS Code
1. Install Python 3.10+.
2. Open this folder in VS Code.
3. Terminal: `python -m venv venv`
4. Windows: `venv\\Scripts\\activate` | Mac/Linux: `source venv/bin/activate`
5. `pip install -r requirements.txt`
6. `python app.py`
7. Open http://127.0.0.1:5000

SQLite database `sportswift.db` is created automatically.

## Features
Dashboard, Events, Teams, Match Scheduling, Venues, Results, Add/Delete operations, SQLite persistence, responsive UI.
